# Computer Vision Toolkit

A curated collection of classical and deep-learning-based image
processing and computer vision implementations.

**Author:** Shahid Karim — Associate Professor & Principal Investigator  
**Focus:** Computer Vision · Deep Learning · Image Fusion · Multidimensional Imaging

## Features

- Edge detection (Canny, Sobel)
- Contrast enhancement (Global HE, CLAHE)
- Denoising (Gaussian, Median, Bilateral, Non-Local Means)
- Feature detection & matching (ORB + Lowe's ratio test)
